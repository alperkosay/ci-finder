Web için bir Finder.

React uygulamanıza tek bileşenle gelen, gerçek bir masaüstü dosya yöneticisi kadar hızlı ve klavye dostu bir arayüz.

Tam ekran dene Belgeleri okuyun
Bu bir ekran görüntüsü değil. Dosyaları sürükleyin, sağ tıklayın, Space'e basın.

Arkada sunucu yok: @thefinder/core motorunun kendisi bu sayfada, bellekte tutulan bir sürücüyle çalışıyor. Yenileyince her şey baştan başlar.

theFinder bir React bileşeni, bir CSS dosyası ve tek bir API ucu. Arayüz hiçbir UI kütüphanesine bağlı değil. Sunucu tarafı Web standardı Request → Response üzerine kurulu, bu yüzden Next.js, Bun, Node, Express, Fastify, Koa ve Hono ile aynı kodla çalışıyor. Dosyalar yerel diskte, S3'te ya da ikisinde birden duruyor. Çekirdeğin çalışma zamanı bağımlılığı: sıfır.

Backend'iniz hangisiyse.

Motor tek bir fonksiyon: finder.handler(request) bir Request alır, bir Response döner. Bun, Hono ve Next.js bunu olduğu gibi kullanır; Express, Fastify ve Koa için ince adaptörler hazır.

Yüklemeler parça parça gelir ve sunucu yüklemeler arasında durum tutmaz. Gövde limitine takılmaz, serverless'ta da çalışır.

app/api/files/route.ts

import {
  createTheFinder, createNextRoutes, localDriver, uploadsDir,
} from "@thefinder/next";

const finder = createTheFinder({
  volumes: [{
    id: "uploads",
    driver: localDriver({ root: uploadsDir() }),
    url: "/uploads",
  }],
});

export const runtime = "nodejs";
export const { GET, POST } = createNextRoutes(finder);

server.ts

const driver = localDriver({ root: "./uploads" });
const finder = createTheFinder({
  volumes: [{ id: "files", driver, url: "/uploads" }],
});

Bun.serve({
  routes: {
    "/api/files": finder.handler,
    "/uploads/*": createFileServer({ driver, prefix: "/uploads" }),
  },
});

server.mjs

import { toExpress } from "@thefinder/core/node";

app.all("/api/files", toExpress(finder.handler));
app.get("/uploads/*", toExpress(
  createFileServer({ driver, prefix: "/uploads" }),
));

// express.json() önce çalışmış olsa bile sorun yok:
// adaptör okunmuş gövdeyi yeniden oluşturur.

server.ts

import { toFastify } from "@thefinder/core/node";

fastify.register(toFastify(finder.handler), { prefix: "/api/files" });

// Eklenti kendi kapsamında gövde ayrıştırmayı kapatır.

server.ts

import { toKoa } from "@thefinder/core/node";

router.all("/api/files", toKoa(finder.handler));

index.ts

// Adaptör gerekmez: Hono zaten Web standardı Request kullanır.
app.all("/api/files", (c) => finder.handler(c.req.raw));

Disk de. Bulut da. Aynı anda.

Her depolama bir volume. Kenar çubuğunda yan yana görünürler; aralarında kopyalayıp taşıyabilirsiniz.

multipart · presigned
s3Driver S3 · R2 · MinIO Spaces · Backblaze B2
  • Kendi sürücünüzü yazın. FTP, Azure Blob, Google Drive… StorageDriver arayüzündeki dokuz metodu uygulamak yeterli.
  • Sunucu durum tutmaz. Yükleme oturumu istemcide taşınır; her parçada hedef, izin ve uzantı yeniden doğrulanır.
  • Veritabanı gerekmez. Çöp kutusu, sürümler ve küçük resimler volume içindeki gizli .tf-* klasörlerinde durur.

İçinde gelenler.

Monaco yok, CodeMirror yok, CDN'den yüklenen bir şey yok. Editörler paketin kendisinde.

Kod editörü

13 dil ailesi için renklendirme, bul ve değiştir, satıra git, akıllı girinti, Ctrl+S ile kaydetme. Kaydetmeden önce eski hal sürüm geçmişine girer.

Markdown

Yan yana önizlemeli düzenleme. Ham HTML işlenmez, bağlantılar güvenli şemalarla sınırlı; güvenilmeyen bir dosyayı açmak zararsızdır.

Görsel editörü

Kırp, döndür, çevir, yeniden boyutlandır; biçim ve kalite seç. Seçili görselleri toplu olarak WebP ya da AVIF'e çevir.

Hızlı bakış

Space ile görsel, video, ses, PDF, kod ve Markdown önizlemesi. Video ileri sarma Range istekleriyle çalışır.

Dosya seçici

useFilePicker bir Promise döner: formunuza “Dosya seç” düğmesi eklemek üç satır. React dışında openFilePicker.

CKEditor

CKEditor 5 eklentisi ve CKEditor 4 connector'ı. CKFinder'ın işini görür: araç çubuğu düğmesi, yapıştırılan görsellerin yüklenmesi.

Güvenlik, varsayılan olarak açık.

Bir dosya yöneticisi sunucunuza yazma izni demektir. theFinder bunu ilk günden ciddiye alır.

Path traversal
.. içeren yollar çözülmeye çalışılmaz, reddedilir. Kök dışını gösteren symlink'ler gizlenir.
CSRF
Değişiklik yapan her istek POST olmak ve x-thefinder başlığını taşımak zorunda.
Arşivler
Zip-slip ve zip bombası koruması. Açılan toplam boyut sınırlı.
Aktif içerik
Yüklenen HTML ve SVG, sandbox CSP ile sunulur; sitenizin origin'inde script çalıştıramaz.
Yetkilendirme
Her komuttan önce authorize. 401, 403 ya da istek bazında salt okunur mod.
İzinler
Volume bazında readOnly, yol bazında permission, uzantı listeleri ve boyut sınırı.

theFinder ve elFinder.

elFinder, web dosya yöneticileri denince akla gelen ilk isim ve on beş yılı aşkın süredir sahada. theFinder aynı işi bugünün yığınıyla yeniden düşünüyor. İkisi de iyi araçlar; hangisinin size uyduğu, projenizin nasıl kurulduğuna bağlı.

theFinder'ı seçin, eğer

  • Uygulamanız React, Next.js ya da bir JavaScript sunucusu üzerindeyse,
  • dosyalar S3 ya da R2'de duruyorsa veya serverless'ta çalışıyorsanız,
  • sürüm geçmişi, çöp kutusu ve görsel optimizasyonu kurulumla gelsin istiyorsanız,
  • arayüzün tasarım sisteminize CSS değişkenleriyle uymasını istiyorsanız.

elFinder'da kalın, eğer

  • Sunucunuz PHP ise ve öyle kalacaksa,
  • Dropbox, Google Drive ya da FTP'ye bugün bağlanmanız gerekiyorsa,
  • tar, 7z, rar gibi arşivlerle çalışıyorsanız,
  • Türkçe ve İngilizce dışında dillere hazır çeviri gerekiyorsa.

elFinder bilgileri 2.1 serisinin belgelerine göre derlendi. Yanlış ya da eskimiş bir satır görürseniz bir issue açın.
